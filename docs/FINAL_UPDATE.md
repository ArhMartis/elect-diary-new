## 🧪 Тестирование

### 1. Удаление классного руководителя
```

3. Нажать "Удалить" рядом с ФИО

```

### 2. Фильтр предметов
```
1. /admin/subjects
2. Прокрутить до "Предметы по классам"
3. Видны кнопки 5, 6, 7, 8, 9, 10, 11
4. Количество классов соответствует БД
```

### 3. Дневник
```
1. /diary (или нажать "Дневник" в админке)
2. Модальное окно выбора
3. Выбрать класс → загрузка из БД
4. Выбрать ученика → загрузка из БД
5. Нажать "Продолжить" → дневник открыт
```

## 💡 Примечания

1. **Все данные загружаются из БД**
   - Классы: `groups`
   - Ученики: `users`
   - Учителя: `users`

2. **Кнопка "Дневник" доступна всем**
   - Маршрут `/diary` для всех ролей
   - Разные интерфейсы для разных ролей (в разработке)

3. **Фильтр предметов автогенерируется**
   - Номера классов извлекаются из названий
   - Сортируются по возрастанию

4. **ФИО классного вместо email**
   - Отображается `fullName`
   - Email скрыт
