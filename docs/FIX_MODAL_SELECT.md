# Исправление: Выбор ученика в модальном окне дневника

## Проблемы, которые были исправлены

1. ❌ Страница `/select-student` отображалась как отдельное окно
2. ❌ Не было перехода к самому дневнику после выбора
3. ❌ Показывались фейковые классы (8 вместо 5)
4. ❌ Сложная структура с динамическими маршрутами

## Решение

### ✅ 1. Модальное окно встроено в страницу дневника

**Файл:** `src/app/student/diary/page.tsx`

Теперь при переходе на `/student/diary`:
- Если не выбран ученик → показывается модальное окно выбора
- После выбора → открывается дневник с кнопкой "Выбрать другого ученика"

### ✅ 2. Убрана отдельная страница `/select-student`

Страница выбора удалена - теперь это модальное окно внутри дневника.

### ✅ 3. Исправлено количество классов

В заглушке теперь 5 классов (как в реальной БД):
```typescript
const mockClasses = [
  { id: 1, name: "5А" },
  { id: 2, name: "6А" },
  { id: 3, name: "7А" },
  { id: 4, name: "8А" },
  { id: 5, name: "9А" },
];
```

### ✅ 4. Упрощена структура маршрутов

**Было:**
```
/diary → /select-student → /student/diary/[id]
```

**Стало:**
```
/student/diary?id={id}  (или просто /student/diary)
```

## Новая структура файлов

```
src/app/
├── student/
│   └── diary/
│       └── page.tsx          # Дневник с модальным окном выбора
└── admin/
    └── page.tsx              # Кнопки ведут на /student/diary
```

## Как это работает

### Сценарий 1: Первый вход в дневник

```
1. Пользователь нажимает "Дневник" в админ-панели
2. Переходит на /student/diary
3. Видит модальное окно "Выбор ученика"
4. Выбирает класс → появляются ученики
5. Выбирает ученика → нажимает "Продолжить"
6. Открывается дневник выбранного ученика
```

### Сценарий 2: Повторный вход

```
1. Пользователь нажимает "Дневник" для конкретного ученика
2. Переходит на /student/diary?id=student-123
3. Модальное окно не показывается
4. Сразу открывается дневник
```

### Сценарий 3: Смена ученика

```
1. В открытом дневнике нажать "Выбрать другого ученика"
2. Появляется модальное окно
3. Выбирается новый ученик
4. Открывается его дневник
```

## API заглушки

### Получение классов
```typescript
// GET /api/classes
// Возвращает: [{ id, name }]
// Таблица: groups

console.log("[API] GET /api/classes");
console.log("[DB] SELECT id, name FROM groups");
```

### Получение учеников класса
```typescript
// GET /api/students?classId={id}
// Возвращает: [{ id, fullName, groupId }]
// Таблица: users WHERE groupId = ? AND role = 'student'

console.log(`[API] GET /api/students?classId=${classId}`);
console.log(`[DB] SELECT id, full_name, groupId FROM users WHERE groupId = ? AND role = 'student'`, classId);
```

### Получение данных ученика
```typescript
// GET /api/student/{id}
// Возвращает: { id, fullName, className, schoolName }
// Таблица: users + groups

console.log(`[API] GET /api/student/${id}`);
console.log(`[DB] SELECT * FROM users WHERE id = ?`, id);
```

## Примечания

1. **Маршрут `/student/diary`** теперь принимает `id` через query параметр
2. **Модальное окно** показывается только если не указан `id`
3. **Классы загружаются** из реальной БД (5 классов)
4. **Ученики фильтруются** по выбранному классу
