Панель директора доступна по маршруту /principal только пользователям с ролью principal. Интерфейс директора предоставляет несколько форм для мониторинга и контроля образовательного процесса.

Управление постами (/principal/posts). Раздел идентичен административному управлению постами, но от лица директора. Директор может создавать, редактировать и удалять новости и объявления школы, которые отображаются на главной странице сайта.

Статистические таблицы. На главной странице панели директора расположены три интерактивные таблицы:

«Всего учителей» — показывает количество учителей в системе. При нажатии открывается подробная информация: кто из них является классным руководителем, какие предметы ведёт каждый учитель, а также сколько часов выделено ему на текущую четверть (с разбивкой по классам и суммарно за неделю).

«Всего учеников» — отображает список всех учеников с указанием фамилии, имени, отчества, электронной почты и класса. При нажатии на конкретного ученика директор может перейти в его дневник для проверки успеваемости и посещаемости.

«Всего классов» — показывает список всех классов, имеющихся в базе данных. Для каждого класса отображается количество учеников и классный руководитель. При детальном просмотре доступна информация о предметах, изучаемых в классе, и учителях, которые их ведут.

Все данные в панели директора отображаются в режиме «только чтение». Директор не может редактировать пользователей, классы, предметы или расписание — он только просматривает и анализирует информацию.

Профиль директора (/director). Отдельная общедоступная страница, на которой отображается информация о руководителе учреждения образования: ФИО (автоматически подставляется из первого пользователя с ролью principal), телефон (синхронизируется из раздела «Контакты» в дневнике, единая точка управления), режим работы по дням недели (Пн–Пт с возможностью индивидуальной настройки для каждого дня, Сб–Вс — выходной), а также график приёма граждан. Для пользователей с ролью admin доступна кнопка «Редактировать», позволяющая изменять все поля, кроме телефона (телефон управляется через Контакты школы). На этой же странице для всех ролей, кроме admin и principal, доступна кнопка «Связаться с директором», которая открывает модальное окно для отправки сообщения директору. Отправленные сообщения попадают в личные сообщения директора и отображаются во вкладке «Обращения» в разделе сообщений.

Профиль директора в боковом меню. В сайдбаре (Drawer), доступном на всех страницах, отображается блок с краткой информацией о директоре: ФИО и телефон. При нажатии на этот блок пользователь переходит на страницу /director с полной информацией. Блок отображается для всех авторизованных пользователей.

Система сообщений. В разделе сообщений реализована вкладка «Обращения», доступная администратору и директору. В ней отображаются все входящие сообщения от пользователей, не являющихся администраторами или директорами (ученики, учителя, родители). Для каждого обращения отображается отправитель, его роль, дата и текст сообщения. Непрочитанные обращения подсвечиваются и имеют счётчик на вкладке. Это позволяет директору быстро реагировать на вопросы и предложения от участников образовательного процесса.

Онлайн-статус и уведомления. В системе сообщений реализован онлайн-статус собеседников — если пользователь был активен в течение последних 2 минут, рядом с его аватаром отображается зелёная точка. На иконке гамбургер-меню (три полоски) в навигационной панели отображается красный бейдж с количеством непрочитанных сообщений, видимый сразу без открытия бокового меню. Вкладки «Чаты» и «Обращения» имеют собственные счётчики непрочитанных.
